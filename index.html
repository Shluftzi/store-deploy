Unified store pipeline

The same six steps apply to every app on both stores. Status cards below map each app to where it sits in this process.

  1. 1

    Prep

    Confirm packaging, versioning, store listings, privacy/compliance, and signing readiness before a build is cut.

  2. 2

    Build

    Produce the store-ready binary (AAB / IPA) from the release branch with the agreed version and build numbers.

  3. 3

    Sign

    Apply Play App Signing / upload key or Apple distribution identity and provisioning so the store will accept the artifact.

  4. 4

    Submit

    Upload the signed build and complete listing, pricing, and questionnaire fields in Play Console or App Store Connect.

  5. 5

    Review

    Wait for platform review; address any rejections or required metadata / policy fixes until approved.

  6. 6

    Release

    Roll out to production (staged or full). Release / QA owns the final GO / NO-GO gate.

Store checklists

Google Play

  • Play App Signing enrolled; upload key registered
  • AAB (not sideload APK) for the target package
  • versionName / versionCode aligned with release notes
  • Store listing, graphics, content rating, Data safety
  • Target API / Play policy compliance
  • Internal / closed track smoke before production

Apple App Store

  • Distribution cert + App Store provisioning profile
  • Archive / IPA from Xcode or CI with correct bundle ID
  • CFBundleShortVersionString / CFBundleVersion set
  • App Store Connect listing, screenshots, privacy nutrition
  • Export compliance / encryption answers
  • TestFlight smoke before App Review submit
